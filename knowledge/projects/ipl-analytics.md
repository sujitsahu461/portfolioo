# IPL Analytics — Crunch-26

## Problem
IPL cricket data analysis typically starts as monolithic Jupyter notebooks that are hard to maintain, reuse, and scale.

## Solution
A comprehensive Python-based IPL data analytics project, refactored from a monolithic notebook into a modular Python package for optimized data processing and professional-grade visualizations.

## Key Features
- Modular Python package architecture (refactored from monolithic notebook)
- Optimized data processing with Pandas
- Professional-grade data visualizations
- Clean, reusable analytics pipeline
