# BullLens — Smart Stock Market Predictor

## Problem
Stock market analysis requires processing large amounts of real-time data and applying predictive models to forecast prices and assess risk. Traditional tools are either too complex or lack AI-powered insights.

## Solution
An AI-powered stock market predictor that combines machine learning models with real-time market data for intelligent forecasting and risk analysis.

## Architecture
- **Backend**: FastAPI (Python) for high-performance async API
- **ML Models**: Machine learning models for price forecasting, volatility prediction, and risk scoring
- **Data**: Real-time stock data from yfinance
- **Database**: MySQL for persistent data storage
- **Vision**: YOLOv8 computer vision capabilities for advanced chart analysis
- **Frontend**: Dynamic Single Page Application

## Key Features
- Stock price forecasting using machine learning
- Volatility prediction and risk scoring
- Real-time data integration from yfinance
- YOLOv8 vision capabilities for chart pattern analysis
- Dynamic SPA frontend for interactive data exploration

## Technologies
Python, FastAPI, Machine Learning, MySQL, yfinance, YOLOv8, Real-time Data, SPA
