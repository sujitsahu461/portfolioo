# Real-Time Weather Dashboard

## Problem
Users need quick, accurate access to weather information for their location without navigating complex weather services.

## Solution
A web-based weather application that provides real-time weather data including temperature, humidity, wind, visibility, rain chance, and AQI using the OpenWeather API.

## Key Features
- Real-time weather data (temperature, humidity, wind, visibility, rain chance, AQI)
- City search functionality
- Geolocation support for automatic location detection
- Temperature unit toggle (°C/°F)
- Responsive, user-friendly interface with helpful tips

## Technologies
JavaScript, OpenWeather API, HTML5, CSS3, Geolocation API, Responsive Design

## Sujit's Role
Solo developer — built the entire application including API integration, geolocation, and responsive UI.
