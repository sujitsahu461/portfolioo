# Finn-Track-Pro — Personal Finance Tracker

## Problem
Personal finance management requires a reliable, secure system for tracking expenses, income, and budgets. Most lightweight solutions lack proper backend architecture and data persistence.

## Solution
A production-grade full-stack personal finance tracker with expense management, income tracking, and budget analytics.

## Architecture
- **Frontend**: JavaScript SPA hosted on Vercel
- **Backend**: REST API with robust input validation and rate-limiting
- **Database**: PostgreSQL on Neon (cloud-hosted)
- **Deployment**: Frontend on Vercel, Backend on Render

## Key Features
- Expense and income tracking
- Budget analytics and reporting
- Secure REST API backend
- Input validation and rate-limiting for enterprise-level reliability
- Cloud-hosted database (Neon PostgreSQL)

## Technologies
JavaScript, Full-Stack, PostgreSQL, REST API, Vercel, Render, Neon
